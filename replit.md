# Kedros landing page

## Overview

This is a single-page React and Tailwind CSS frontend for Kedros, a custom software and business development studio.

## Running locally

- `npm run dev` starts the Vite development server on port 5000.
- `npm run build` creates a production build in `dist/`.

The contact form is intentionally display-only. It shows a local confirmation state and does not send or persist messages.
